# Big Wave · Thư viện LadiPage

Trang tổng quản lý 199 dự án LadiPage, chia 8 hạng mục.

- 126 trang web liên quan cho 138 dự án.
- 61 dự án chỉ có file gốc.
- Giữ nguyên hai gói ZIP gốc; ZIP trùng được gộp.
- Ghi chú và yêu thích lưu trên trình duyệt, có thể xuất/nhập JSON.

Các trang khôi phục từ bản web đã xuất bản có thể khác phiên bản file .ladipage mã hóa.
